Security & Safety

Owner accounts cannot be disabled or deleted. Admin mutations require the current session CSRF token. Passwords use scrypt hashes. Destructive account deletion requires browser confirmation. Infrastructure secrets and Render restart/deploy controls are intentionally not exposed here, so the panel cannot accidentally break the running service.
